RISKSPEC MVP — QUICK START

1. Download both files:
   - RiskSpec_MVP.html
   - RiskSpec_Jupyter_Launcher.ipynb

2. Put both files in the same folder.

3. Open RiskSpec_Jupyter_Launcher.ipynb in Jupyter Notebook or JupyterLab.

4. Run the first code cell to display the app inside Jupyter.

5. Run the second code cell to open it in a full browser window for recording.

WHAT WORKS
- Dashboard navigation
- Search and filter transactions
- Click transaction rows for details
- Simulate a new transaction
- Run explainable AI analysis
- Generate an audit record
- Download transactions as CSV
- Change risk threshold
- Technical architecture page

NOTE
This is an interactive front-end MVP using simulated data. Present it honestly as a prototype, not as a deployed AI system.
